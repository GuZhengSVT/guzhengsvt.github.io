Open the logbookSource on GitHub

Amateur Radio Logbook

BI9CKE QSL Logbook

This is my personal station logbook. The frontend is hosted on GitHub Pages, with the management backend on Cloudflare.
I haven’t had time to import my records yet, so the contacts currently shown are test data.

  • Logs and cards: search contacts, browse QSL cards, track paper and LoTW confirmations, and import or export ADIF files.
  • Maps and statistics: explore contact coverage, activity over time, and progress across DXCC entities and grid squares.
  • Station tools: check propagation conditions and calculate satellite tracks, passes and Doppler shifts before getting on the air.

The public interface supports Chinese and English, mobile layouts and light/dark themes. Cloudflare Workers and D1 handle log management and station settings.

AI news collection and delivery: Newspaper gathers, cross-checks and organizes stories by topic, then publishes them on the web, by email and on Telegram.

Read NewspaperGenerator on GitHubPublished site on GitHub

Newspaper

AI news collection and delivery

AI slop is multiplying at an absurd rate, making it harder to find information efficiently and reliably. Finding sources, cross-checking and deduplicating stories, and assessing importance and reliability can all be handed to AI. Spending some tokens saves a lot of searching and asking around myself.
I recently picked up a 2-vCPU, 2-GB VPS from Huawei Cloud for RMB 36 for eighteen months. This is the first project I’ve put on it: collect and organize news by section on a schedule, build webpages, a database and Markdown documents, then deliver the results through email and a Telegram bot.
I could have pointed the domain straight at the VPS, but a mainland China server means dealing with ICP filing. Too much hassle. Instead, once a task finishes building the site, it pushes the result to a GitHub repository. The domain points to GitHub Pages, which also makes access more stable.
I’m starting to feel a bit guilty about how much free hosting I’m getting out of GitHub, honestly (

  • Configurable editions: choose topics, sources and daily, weekly or monthly schedules.
  • Reading and delivery: archive search, RSS, Markdown and JSON downloads, plus email and Telegram delivery.
  • Independent operation: generation does not need a local computer or an Agent chat window left open. The program, personal configuration and published site are maintained separately.
  • Why this over scheduled Harness tasks? Use ordinary code for the parts that ordinary code can handle, and summarize each section separately to avoid huge contexts. Basically: save tokens.

My news site currently has two main groups: “Technology & Politics” and “ACGN.” The generator is open source, so you can configure your own news sections and requirements. The separate site repository contains the published pages.

Ruri

A minimal, flat, lightweight Hugo theme for personal blogs

This blog runs on Ruri, named after the Japanese word for lapis lazuli. I used Reimu for a long time and wanted to give the pages a cleaner look. When I first got into personal websites at fourteen, every configuration change felt impossibly hard. Fortunately, this is the AI era: with the powers of GPT and DeepSeek, I rebuilt the layout and interactions on top of Reimu. It worked well enough for my own use, so I separated out my personal content and settings and released it as a standalone theme (although I think anyone can make their own custom theme these days).

It mainly uses Hugo templates, vanilla JavaScript and CSS/SCSS, without adding a frontend framework.

  • Pages and reading: responsive layouts, light/dark themes, collapsible contents, code copying and folding, image lightboxes, KaTeX math and Mermaid diagrams.
  • Music and navigation: a floating player with playlists, lyrics, volume and playback order controls. Music keeps playing while navigating between pages within the site.
  • Blog essentials: Pagefind full-text search, RSS, Waline comments, friend links, an archive timeline and a writing heatmap, plus optional arts and culture collections and project introduction pages.
  • Configuration and languages: Simplified Chinese, Traditional Chinese, English and Japanese interfaces. Personal copy, menus and external services stay in your own site configuration; the theme includes generic examples and Chinese/English documentation.

Install through either Hugo Modules or a Git submodule. The theme code is MIT licensed, with Reimu attribution and the relevant license notices retained.

Live Watcher is a macOS app that notifies you when Bilibili streamers go live. No Bilibili account sign-in is required. Customize notification rules, subscribe to streamers’ weekly schedules via HTTPS or webcal, and choose from three sizes of desktop widget.

Source on GitHub

Live Watcher

A macOS app for Bilibili live status and weekly schedules

When I’m working on my Mac, I don’t want to open a browser and scroll through a list just to see if a creator I follow is live. So I vibe-coded this little app. There’s no Bilibili login: add a streamer using their UID, profile URL or live room link.

  • Live status: check automatically or on demand. Streamers who are live move to the top, with a preview, title, category and concurrent viewer count. Click to open the live room.
  • Go-live notifications: set category rules across the app or configure notifications for individual streamers to cut down on interruptions.
  • Weekly schedule subscriptions: import HTTPS or webcal calendar links and view streamers’ upcoming broadcasts together on one timeline.
  • Appearance and widgets: choose light, dark or system appearance, with five color schemes and adjustable text size. Small, medium and large desktop widgets show who’s live.

The app is written natively in Swift for macOS 14 and later. Version 0.1.1 was released as a beta, and the source is available under GPL-3.0-or-later.

業餘無線電通聯日誌

BI9CKE QSL Logbook

這是我的個人電臺日誌。前端部署在 GitHub Pages，後臺管理在 Cloudflare。
相關資訊還沒空匯入，目前的通聯資料是測試案例。

  • 日誌與卡片：搜尋通聯記錄，查看 QSL 卡片相簿，管理紙卡和 LoTW 確認狀態，支援 ADIF 匯入匯出。
  • 地圖與統計：查看通聯覆蓋、活動變化，以及 DXCC 和網格的探索進度。
  • 電臺小工具：查看傳播狀況，計算衛星軌跡、過境時間與都卜勒頻移，為實際通聯做準備。

前臺支援中英文、手機版面和深淺色模式；後臺用 Cloudflare Workers 和 D1 儲存日誌與電臺設定。

Newspaper

AI 新聞整理與推送

AI 時代數位餿水的數量核爆級增長，如何高效可靠地獲取資訊變成更為嚴峻的考驗。資訊來源、交叉驗證去重、重要性分析、可靠性分析都可以交給 AI，只要花 token 就可以大幅減少自己搜尋和提問的時間。
最近從華為雲花 36 塊嫖了一年半的 2C2G VPS，這是第一個專案。將新聞內容分板塊定時蒐集整理，建構網頁、資料庫和 MD 文件，透過 E-mail 與 Telegram Bot 推送。
本來 VPS 可以直接綁定網域的，但中國大陸伺服器還要備案，太麻煩了。設定在任務結束、網站建構好後推送到 GitHub 儲存庫，把網域綁定到 GitHub Pages，存取更穩定。
感覺白嫖 GitHub 有點太多了，怪不好意思的（

  • 按主題出刊：話題、來源和更新週期可以自己設定，支援日報、週報和月報。
  • 閱讀與訂閱：提供封存搜尋、RSS、Markdown 和 JSON 下載，也支援郵件與 Telegram 推送。
  • 獨立執行：產生任務不依賴一直開著的本地電腦或 Agent 聊天視窗；程式、個人設定和發布網站分別維護。
  • 相比 Harness 定時任務的優勢：能用電腦程式解決的流程就用程式，分板塊執行摘要任務，避免超長上下文，總之就是省 token。

我的新聞網站目前分為「科技與政治」和「ACGN」兩個一級板塊。產生程式開源，可以拿來設定自己的新聞板塊和需求，網站儲存庫則保存對外發布的頁面。

Ruri

極簡、平面、輕量的 Hugo 個人部落格主題

這個部落格現在用的就是 Ruri，名字取自日語的「琉璃」。之前一直用 Reimu（靈夢），想把頁面改得清爽一點。在我 14 歲剛接觸個人網站那會兒，任何設定和改動都難如登天。好在現在是 AI 時代，借助 GPT 和 DeepSeek 神力，在 Reimu 的基礎上重新做了一套版面和互動。改完自己用著還行，就把個人內容和設定拆出去，整理成了獨立主題發布（雖然我覺得，在這個時代每個人都可以做自己的客製主題）。

主要用 Hugo 模板、原生 JavaScript 和 CSS／SCSS 實作，沒有額外引入前端框架。

  • 頁面與閱讀：響應式版面、深淺色模式、可摺疊目錄、程式碼複製與摺疊、圖片燈箱，也支援 KaTeX 數學公式和 Mermaid 圖表。
  • 音樂與導覽：浮動播放器支援播放清單、歌詞、音量和播放順序；站內切換頁面時保留正在播放的音樂。
  • 部落格常用功能：Pagefind 全文搜尋、RSS、Waline 留言、友站連結、封存時間樹和寫作熱力圖，以及可選的文藝收藏頁面、專案介紹頁面。
  • 設定與多語言：提供簡中、繁中、英文和日文介面。個人文案、選單、外部服務放在自己的網站設定裡，主題附有通用範例和中英文說明。

支援 Hugo Module 和 Git submodule 兩種安裝方式。主題程式碼採用 MIT 協議，保留 Reimu 的署名與相關授權說明。
